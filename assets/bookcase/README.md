# Bookcase source files

These are the untouched files from `wooden-bookcases-with-books.zip`:

- `source/Victorian Bookcase Tall and Small.fbx` is the source scene.
- `textures/` contains its original full-resolution texture maps.

The web app loads optimized copies from `public/models/` so the browser does not download the original 4K texture maps. Keep the source copies here if you need to re-export or edit the model.
